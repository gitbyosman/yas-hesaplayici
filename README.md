# Age Calculator / Yaş Hesaplayıcı v1.1

**Latest version:** 1.1 — 2025-10-18

---

## English Version

This simple web app calculates your **age in years, months, and days** based on your birth date. It also shows how many days remain until your next birthday.

### Features
- Easy and fast to use
- Modern design and mobile-friendly
- PWA (Progressive Web App) support
- Can be added to home screen for app-like experience

### How to Use
1. Select your birth date
2. Click the "Calculate" button
3. Your age and days until next birthday will be displayed immediately

### Technologies
- HTML / CSS / JavaScript
- PWA support (manifest.json & service-worker.js)

## Türkçe Versiyon
